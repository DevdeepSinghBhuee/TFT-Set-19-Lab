# TFT Set 19 Lab

Personal test notebook for Teamfight Tactics Set 19 (Prismatic Tour): champion and trait database, unlock quests, team builder, tier list, early-game and gold reference, item recipes.

Single static page (`index.html`), no build step. Comps and tier lists are stored in the browser; use Export / Import to move them between devices.
